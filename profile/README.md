# Wardio

Managed Linux servers for small businesses, run from Denmark by David Kabel.
Monitoring, patching, intrusion detection and verified off-site backups, on
one monthly price.

- Website: [wardio.net](https://wardio.net)
- Guides: [wardio.net/guides](https://wardio.net/guides/). Each technical claim
  is checked against primary sources, and the commands are run in a test
  environment before a guide is published.
- [restic-append-only](https://github.com/Wardio/restic-append-only): a tested
  reference design for restic on object storage with a server key that cannot
  delete backup data, including what it does not protect and what it costs.
